# Blueprints

A maximalist, opinionated meta repository serving as a personal engineering standard for various tech stacks via copier templates that handle the heavy lifting of setting up projects with consistent structure, tooling, and processes, so you can focus on writing code rather than configuring your development environment. This includes handling engineering decisions, tooling, project structure, quality, CI/CD and more.
